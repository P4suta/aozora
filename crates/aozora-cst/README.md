# aozora-cst

A lossless concrete syntax tree for Aozora Bunko notation.

**Internal crate.** No stability contract — the API can change in any
release. Reach it through the [`aozora`](https://crates.io/crates/aozora) crate's
`cst` feature.

Part of the [aozora](https://github.com/P4suta/aozora) workspace.
